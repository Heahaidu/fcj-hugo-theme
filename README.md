# FCJ Hugo Theme

[![Hugo](https://img.shields.io/badge/hugo-0.16-blue.svg)](https://gohugo.io) ![Build with Hugo](https://github.com/alex-shpak/hugo-book/workflows/Build%20with%20Hugo/badge.svg)

## Installation

Navigate to your hugo project root and run:

```
git submodule add https://github.com/Heahaidu/fcj-hugo-theme themes/fcj-theme
```

Set the theme in your Hugo configuration file `hugo.toml`:

```
theme = "fcj-theme"
```

Then run the development server:

```
hugo server --theme fcj-theme
```
